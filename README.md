# スタンプ申請キット

LINEスタンプ・絵文字・着せかえの申請用画像を、カット・透過・重複チェック・規格変換・ZIP保存まで行うブラウザツールです。
パソコンでもスマホでも、同じURLで使えます。画像はブラウザ内で処理され、サーバーへは送信されません。

## GitHub Pagesでの公開
1. GitHubで新しい公開リポジトリを作ります（例：stamp-kit）。
2. このフォルダの中身（index.html・site.webmanifest・アイコン画像・.nojekyll）をリポジトリ直下にアップロードします。
3. Settings → Pages → Build and deployment で「Deploy from a branch」→ main / (root) → Save。
4. 数分後に https://<ユーザー名>.github.io/<リポジトリ名>/ で使えるようになります。

## 更新するとき
新しい index.html を同じ場所に上書きアップロードするだけで、URLは変わりません。
